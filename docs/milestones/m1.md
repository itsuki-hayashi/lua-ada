# M1: Basic Lua Scripting Interpreter

Accepted: 2026-11-05. Status: **active, not complete**.

## Completion target

Execute useful standalone Lua 5.5.1 scripts through a batch CLI and a minimal
Ada embedding interface. Libraries, AUnit, ABI feasibility, and CI are gates
within this milestone, replacing the original infrastructure-only M1.

| Area       | Required M1 behavior                                                  |
| ---------- | --------------------------------------------------------------------- |
| Values     | Nil, booleans, 64-bit integers, doubles, byte strings                 |
| Operators  | Primitive arithmetic/bitwise/comparison, concatenation, length, logic |
| Variables  | Lexical scope, globals, _ENV, Lua 5.5 global declarations, constants  |
| Statements | Assignment, blocks, conditionals, all loop forms, break, return       |
| Functions  | Closures, recursion, mutation, varargs, multiple results, tail calls  |
| Tables     | Constructors, indexing, mutation, identity, sequences, iteration      |
| Errors     | Located syntax/runtime errors, protected calls, resource limits       |
| Lifetime   | Tracing collection, including unreachable cycles                      |

Include Lua literals/escapes, long strings/comments, precedence, evaluation
order, and result adjustment. Base functions: print, assert, error, pcall, type,
tonumber, tostring, select, next, pairs, ipairs, rawequal, rawget, rawset, rawlen.
Provide _G and _VERSION; the CLI supplies arg.

Defer metatables/metamethods, coroutines, userdata, <close>, labels/goto,
binary chunks, runtime source loading, and other standard libraries. Recognize
deferred syntax explicitly. Do not claim complete Lua support.

## Interfaces

Use a reusable static/shared Ada library, separate CLI, nested AUnit crate,
lexer, resolving parser, private typed register bytecode, and VM. A session
owns globals, heap, stacks, and roots; start with stop-the-world tracing GC.
Investigate ABI constraints before fixing heap/frame representations.

The Ada interface owns session lifetime, executes named source chunks, retains
globals, captures output, and returns structured syntax/runtime/resource errors.
Language failures must not escape as Ada exceptions. Chunk return values may be
discarded; object manipulation and host callback registration remain deferred.

The batch CLI must support files, repeated -e snippets, explicit stdin, script
arguments, --, help/version, stderr diagnostics, and failure status. No input
displays usage. A REPL is deferred. Only help/version/failure exists today.

## Gates and acceptance

1. Build/tests: library modes, meaningful AUnit, strict profiles, three-OS CI.
2. Constraints: ABI experiments, inventory, differential runner, ownership decisions.
3. Substrate: numbers/strings, tables, heap, roots, frames, tracing collection.
4. Execution: resolving frontend, register code, control flow, functions, results.
5. Usability: base library, Ada sessions, batch CLI, diagnostics, acceptance suite.

Require AUnit boundary/ownership tests and differential scripts for recursion,
closures, result adjustment, loops, tables, short circuit, and protected errors.
Test cyclic reclamation, live captures, independent sessions, recoverability,
resource limits, CLI modes, and a real Ada session consumer.

All three OS targets must pass static/shared acceptance suites before completion.
Inventory applicable unchanged upstream tests and deferred coverage. Reduced
coverage is not full upstream conformance. See [status](../status.md) and
[backlog](../backlog.md).
