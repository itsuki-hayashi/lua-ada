# Public optimizer semantics witnesses (2026-11-08)

Root's code-private-optimizer feature decision permits only separately reviewed
private structure exclusions with retained semantic obligations. This component
adds a public Lua fixture and separately named AUnit cases, with exact pinned
source links in code-public-semantics.author-witness.json. It changes no
production code, private optimizer proposal, exclusion, adapted code.lua,
original checkR bytes or source-ledger disposition.

Twenty-nine cases execute the fourteen checkK/checkI/checkF expressions, both
five-value immediate-boundary groups and three generated hexadecimal checkints
round trips. Each scalar result is packed once and checked for exact value,
math.type and one-result cardinality. Nested constant maker/middle/leaf functions
execute with one result per layer; stripped and unstripped dumps reload and
execute their actual returned functions and fifty-byte string.

The original callback function executes all eight numeric arguments in order;
the observer checks one argument each and integer/float alternation. The
fourteen repeated table assignments use an absent-key __newindex recorder
which deliberately leaves the receiver empty, so every assignment's actual
receiver/key/value and numeric kind is observed. Neither witness invents a
listk/listcode facade.

The 49/50/51 constructor controls preserve successful compilation/execution of
the original nil-valued form and add direct prefix-slot, exact trailing-value,
numeric-kind, public iteration and one-table-return checks for zero, one and
multiple varargs. They do not assume a length at an interior nil hole.
Separate zero, one-nil and multiple-result controls retain counts/kinds through
dump/load. The original valid/oversized register-load controls compile their
source and check the diagnostic without calling the intentionally nil callee.
Other intentionally invalid/infinite opcode-only closures are not executed.
