# M3-02A: Execution Context Ownership

Date: 2026-11-06, Asia/Tokyo. Branch: codex/m3-02-execution-contexts.
Baseline: master d708130632ba74c7013ac67beab6089b249715a8 (merged PR #5).

## Implementation

World owns registered private execution contexts and borrows its current context
through a selector. Frames, arguments, error objects, locations and failure
categories belong to each context. Globals, heap, modules, output and budgets
remain shared. Registration releases a new allocation if vector growth fails.
Selection rejects invalid identifiers and abandoning a running driver.

Collection visits every registered context, including inactive frame captures,
arguments and errors. Finalization releases all activations and contexts before
heap objects and prototypes; repeated finalization is safe. The compiler,
loaders, VM and session adapter now use the current context. No public API or
coroutine language behavior was added.
