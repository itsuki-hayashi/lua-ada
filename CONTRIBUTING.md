# Contributing

Read [AGENTS.md](AGENTS.md), [architecture](ARCHITECTURE.md), and
[development setup](docs/development.md). Human and AI contributions follow
the same quality baseline.

Choose a bounded [backlog](docs/backlog.md) item. Establish expected behavior
from the pinned Lua source and manual. Record consequential ownership, ABI,
dependency, and scope choices in a decision before depending on them.

Keep implementation, relevant documentation, and meaningful regression tests
together. Follow [coding standards](docs/coding-standards.md) and
[testing](docs/testing.md). Never alter upstream tests to hide incompatibility.

Before handoff, review the diff for unrelated changes, generated files, and
submodule drift. Run applicable checks, record exact versions and results,
update backlog evidence/status, and add a session record for substantive AI work.
Describe the problem, resulting behavior, validation, and material limits.

First-party contributions retain MIT licensing. Preserve upstream attribution
and notices when drawing on reference material.
